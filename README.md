# 🛡️ Kawach Cloud

Kawach Cloud is a personal cloud storage app that lets you upload, manage, organize, download, and access your files using your Telegram Saved Messages.

## Features

- Upload files
- Multiple file selection and upload
- Download files
- Organize files and folders
- Search and manage files
- Open photos
- Play videos
- Light and dark mode
- Telegram account connection

## Version
