## ✨ Features

- **Telegram-powered file storage** — Store and sync your files directly in your Telegram Saved Messages.
- **Multiple file upload** — Select and upload multiple photos, videos, and documents at once with sequential queue progress.
- **File and folder management** — Create custom folders and organize files effortlessly.
- **Image preview** — View photos inside the app with full-resolution pinch-to-zoom and pan support.
- **Video playback** — Watch videos directly with a smooth, built-in media player.
- **File download** — Download files directly to your device's public Downloads directory.
- **Search and sorting** — Find files quickly by name and sort by date, name, or size.
- **Light and dark themes** — Clean Material 3 interface with full dark mode and light mode support.
